The course

48 hours (6 credits). 24 hours of theory, and 24 hours of practice, it's a very practical course. There are plenty of technologies we'll be shown, but we don't have to study each of them, it's mostly about understanding the theory and then applying it to understanding one technology, the one that best fits your purposes.

Class begins at 17, and ends at 18:30, despite what the online system says. Formally, two hours, practically, 90 minutes, with no pause. This way, we should finish by the end of November. We can switch to three formal hours per day, and finish early, or we can decide each day if everyone present is okay with three formal hours.

Minimum 70% attendance. You keep track of your own attendance.

Training activities:

  • Attendance of lessons and programming exercises
  • Studying textbooks and notes
  • Research tasks in different fields, using the technologies we learnt about
  • Seminaries, we have a connection with the Italian leader in big data, there's a specific person who has 50 years of big data experience, they've already hired three students coming from this course, and when they hire you they'll let you work from home or assign you to a
  • Practical experimentation
  • Interaction with the teacher
  • Telegram

Technical outline:

  • Hadoop, outdated but important
  • HDFS, a file system
  • MapReduce
  • Spark, better framework
  • Some programming with Spark, RDDs
  • ......... #slide
  • Spark DataFrames

  • Streaming with Spark
  • Amazon AWS

Exam:

  • Written test, in a laboratory, you're assigned a problem to solve in Spark, you can use the Internet but not AI
  • Project, you should come up with your own task and which technology you want to use, you'll work with the professor to perfect the task, then you work on it, one or two people
  • Discussion of the project, even remotely

Your project can be extended into a scientific paper.

You are strongly suggested to use AI. You can learn a lot with it. But you need to know how to use it. Don't make it do things for you, it has to let you understand what you're doing, because if you didn't make the code, you don't know how to change it when the client asks you to. You sketch the code, you do the first step. If you don't understand something or something is new to you, ask AI.

In order to run applications, you need a data center (for big data). An amount of data so big that it cannot be stored in one PC. If so, how can a data center work on them? There are file systems, like HDFS, that are distributed, even supporting storing one file on several hard drives, like a 100 TB file. As such, we will not be working on real big data, as that would cost one million dollars. We'll either make a cluster with two PCs, or have a cluster on one PC, with RAM partitioned between nodes.

We'll use the Linux CLI a lot (the big data framework is installed on Linux, the interface can be used from any OS). We'll use Python. Spark is a framework for Python, Java, Scala and R. Scala is the most efficient language for Spark, as Spark was builty with Scala, and Scala is really close to Python.

Lots of reporting (data, pipeline, methodology, infrastructure, experiments, results).
